# دستیار همراه پیشرفته (Assistance App)

یک سوپراپ و سامانه جامع همراه شخصی، ماژولار و آفلاین طراحی‌شده بر پایه React 19 + TypeScript + Tailwind CSS و Capacitor برای اندروید.

## قابلیت‌های کلیدی
- **داشبورد مینیمال:** نمایش ساعت زنده، تاریخ خورشیدی، تقویم جلالی، نقل‌قول روز و دسترسی به میانبرها
- **پیام‌رسان امن درون‌برنامه‌ای:** چت‌های دسته‌بندی‌شده (شخصی، خانواده، کاری، یادداشت به خود)، وضعیت ارسال/دریافت، ضبط صوت، استیکر و جستجو
- **حسابداری هوشمند و تشخیص سرشماره‌های بانکی:** شناسایی خودکار بانک‌های ایرانی (ملت، ملی، صادرات، تجارت، سامان، پاسارگاد، بلو، رسالت، سپه و ...) از روی سرشماره پیامک و متن واریز/برداشت، تبدیل خودکار ریال به تومان و ثبت پیش‌نویس تراکنش‌ها
- **اسکنر اسناد متوالی و تولید PDF:** اسکن دوربین پشت‌سرهم چندین صفحه، فیلترهای تقویت اسناد (سیاه و سفید، خوانا، خاکستری)، مدیریت و حذف صفحات و دانلود یکپارچه فایل PDF
- **بخش یکپارچه شخصی (Personal):** مدیریت سلامت و علائم حیاتی، گاوصندوق رمزنگاری‌شده (کلمات عبور، کارت‌های بانکی، کلیدها)، ردیاب عادات روزانه و مناسبت‌های مهم
- **بخش یکپارچه ابزارها (Tools):** مانیتورینگ کارکرد و عادات استفاده از برنامه‌های گوشی، دستیار خودرو و سرویس‌های دوره‌ای، ضبط و صورت‌جلسات جلسات صوتی، تنظیمات همگام‌سازی ابری و عیب‌یابی سیستم
- **قابلیت افزودن/حذف پویا:** امکان فعال یا غیرفعال کردن تک‌تک ماژول‌ها مطابق سلیقه کاربر
- **شخصی‌سازی ظاهر:** تم تاریک، روشن، فیروزه‌ای، زعفرانی، سرمه‌ای و حالت کنتراست بالا همراه با تغییر اندازه فونت

## نحوه بیلد و دانلود APK اندروید
این ریپازیتوری مجهز به **GitHub Actions** است:
1. در صفحه گیت‌هاب پروژه به تب **Actions** بروید.
2. آخرین بیلد با نام **Build Android APK** را باز کنید.
3. در انتهای صفحه بخش **Artifacts**، فایل **Assistance-App-Debug-APK** را دانلود کنید. فایل `.apk` آماده نصب روی گوشی است.

---

## راه‌اندازی لوکال پروژه
```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه وب
npm run dev

# ساخت بیلد پروداکشن
npm run build

# همگام‌سازی با اندروید
npx cap sync android
```
